# O que vamos criar?
Vamos criar um RPG, mundo aberto, com quests, NPCs, diálogos. Em 3D, para PC.

# Pontos fracos da IA:
- Gerar arte (lembrando: porque o pessoal odeia)
- Level design

# Jeito CERTO de criar jogos com IA
Vários pontos:
- Lembrar que você (seu prompt) VAI influenciar o resultado
- **Você PRECISA SABER o que está sendo criado**
- Você PRECISA dividir em MILESTONES MENORES e TESTÁVEIS:
    - "Crie um jogo" é MUITO AMPLO
    - **Milestones:**
        1. "Crie um projeto VAZIO (hello world), compilável e funcional para esse projeto X (<especificação>)"
        2. "Crie um sistema de janelas e um triângulo na tela"
        3. "Importe assets"
        4. etc.
- Dar **A MAIOR QUANTIDADE DE DETALHES POSSÍVEL**
